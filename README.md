Enum, Record та Switch у музичному стримінговому каталозі.

## Як запустити

```bash
./gradlew build run
```

У Windows використовуйте `gradlew.bat build run`. Для збірки потрібна Java 21.

## Що змінилося після ЛР1

- `Artist`, `Album`, `Track` і `PlaylistTrack` стали `record` із компактними конструкторами. Їхній згенерований `equals` порівнює всі компоненти.
- `MusicUser` лишився класом із сеттером підписки. `PlaylistTrack` зберігає посилання на користувача, тому зміна підписки видима через цей запис. Рівність самого користувача залежить від його адреси пошти.
- `Genre` і `Subscription` замінили рядки. `BaseEntity` і `createdAt` прибрано, бо каталог не використовує час створення.
- Два `switch`-вирази в `MusicUtils` задають демонстраційні правила підписок. `FREE` має один профіль, `PREMIUM` додає офлайн-прослуховування, а `FAMILY` підтримує офлайн-прослуховування й до шести профілів.

ЛР2 здається через PR `lab2` → `main`. Опис використання AI міститься в `AI.md`.
